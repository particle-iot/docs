# {{title}}

This page walks you through unboxing and setting up a [Photon](/reference/datasheets/wi-fi/photon-datasheet/), a Wi-Fi development board. By the end, the Photon will be powered up and ready to add to your Particle account.

{{note op="start" type="note"}}
This page is for the Photon 1. For the Photon 2, see [Photon 2 setup](/getting-started/device-setup/photon2/).
{{note op="end"}}

{{content-nav}}

## Unboxing

The Photon 1 is available as the Photon 1 only, or as a kit with a solderless breadboard and accessories.

If you have the device only, you will need a USB Micro B cable that is compatible with your computer. Make sure it is a data cable, not just a charger cable.

## What you'll need

- A Photon 1
- A Micro USB B cable for power and data
- A computer (Windows, Mac, or Linux), which you'll use to set up the device and to program it with Particle Workbench
- Your Wi-Fi network name and password

## Prepare the hardware

1. Connect the micro-USB cable between the Photon and your computer. This provides both power and a data connection.

## Add to your account

To add the device to your account and make sure it's running the latest Device OS, go to [setup.particle.io](https://setup.particle.io/). The guided setup will:

- Sign you in, or create a Particle account if you do not have one yet
- Add your Wi-Fi credentials to the device
- Update the Device OS if necessary

## Next steps

Once setup is complete, continue with the [getting started guide](/getting-started/guide/device-setup/) to explore the Particle console and program your device.
