## Particle primitives

In addition to the Particle.publish function we used in the last tutorial, there are 3 more useful primitives:

- Particle.function: Cloud to device trigger
- Particle.variable: Poll a value from the device
- Particle.subscribe: Listen for events on-device

This project will use the Particle.function to update the color of the RGB LED status LED. We'll also use this firmware in the next section, Device fleets.
